## 📂 Featured Projects

### 🧠 [SmartSpend AI](https://github.com/madhavsinghal88/smartspendai) · [Live Demo](https://smartspendai-henna.vercel.app)

An AI-powered personal finance engine for Indian users that turns raw spending data into a clear plan for building wealth.

- **Hybrid AI + deterministic engine:** Gemini handles deep behavioural insights, and a custom math engine takes over instantly if the API times out or hits its quota, so users always get a result
- **Wealth projection:** 10-year compounding trajectory with interactive, responsive charts
- **Smart Swap & Time Machine:** India-specific lifestyle swaps and "what-if" scenarios like starting a SIP or moving cities
- **Privacy-first:** no login, no stored financial data, API keys kept server-side

`Next.js 15` `TypeScript` `Gemini API` `Tailwind CSS` `Recharts` `Framer Motion` `Vercel`

### 💸 [DebtQ](https://github.com/madhavsinghal88/debtq)

A keyboard-driven terminal app for tracking expenses, debts, investments, and savings goals, with Obsidian sync.

- **Borrowing & lending:** groups transactions by person, calculates net balances, and supports partial settlements with payment history
- **Net worth & savings goals:** tracks stocks, mutual funds, FDs, PPF, gold, and crypto; shows the monthly saving needed to hit each goal
- **Obsidian integration:** exports all data as linked Markdown dashboards in your vault
- **Clean architecture:** separate config, models, storage, and TUI layers; local JSON persistence; Makefile-based install

`Go` `Bubble Tea` `Lip Gloss` `JSON` `Make`
